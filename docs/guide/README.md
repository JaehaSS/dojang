# Dojang 사용 가이드

Dojang은 **AI 코딩 에이전트를 여러 개 동시에 굴리고, 그 결과를 검토한 뒤 승인하는 데스크톱 IDE**입니다.

에이전트에게 일을 시키는 것 자체는 터미널에서도 됩니다. Dojang이 맡는 건 그다음입니다 —
**작업마다 격리된 git worktree를 파고**, 에이전트를 그 안에서만 움직이게 하고, 끝나면
**변경 내용을 diff로 보여준 뒤 승인/폐기를 사람이 결정**하게 합니다. 에이전트가 main 브랜치를
직접 건드리는 일이 없습니다.

## 3분 요약

```
지시문 입력  →  격리 worktree 생성  →  에이전트 실행  →  diff 검토  →  승인 or 폐기
                (praxis/<작업명> 브랜치)                         (승인 시 커밋+머지)
```

- **동시에 최대 8개 작업**을 각자의 worktree에서 병렬 실행합니다.
- 지원 에이전트 CLI: **Claude Code · Codex · Agy**(Gemini 계열)
- 승인 전까지 원본 레포는 그대로입니다. 폐기하면 worktree째 사라집니다.
- 작업이 끝나면 **알림**이 오고, 모바일 PWA를 붙여 두면 폰으로도 받습니다.

## 어디서 도는가

| 구성 | 역할 |
|---|---|
| **데스크톱 앱** | 평소 쓰는 본체. GitHub Releases의 dmg로 받거나 소스에서 빌드하며, macOS Apple Silicon 전용입니다 |
| **모바일 PWA** (선택, 베타) | 폰에서 상태를 보고 승인·대화. 데스크톱이 직접 서빙합니다 |

작업은 전부 이 기계에서 돕니다. 원격 서버를 준비할 일이 없습니다.
